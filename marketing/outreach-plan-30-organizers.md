# Outreach Plan — 30 Organizers แรก
> เป้าหมาย: หาผู้จัดทริปจริง 30 คนที่ใช้งานระบบ ไม่ยิงแอด เน้น direct outreach

---

## ภาพรวม Process

```
หา Prospect → คัดกรองด่วน → ส่งข้อความแรก → ติดตาม → นัด Demo 1:1 → ช่วย Setup → Active User
```

เป้าต่อสัปดาห์: ทัก 20 คน → ได้คุย 8 คน → นัด demo 4 คน → active 2 คน  
ใช้เวลาราว 4–6 สัปดาห์ถึง 30 คน

---

## ขั้นตอนที่ 1 — หา Prospect ให้ได้วันละ 10–15 คน

### แหล่งที่ 1: Facebook Groups (เร็วที่สุด)

**กลุ่มที่ต้อง join ก่อน:**
- เดินป่าประเทศไทย / Hiking Thailand
- ปั่นจักรยานทางไกล / Cycling Thailand
- Backpacker ไทย / ท่องเที่ยวแบบประหยัด
- ดำน้ำไทย / Scuba Thailand
- กลุ่มท่องเที่ยวรายจังหวัด (เชียงใหม่, ภูเก็ต, กาญจนบุรี ฯลฯ)
- กลุ่ม Facebook เฉพาะทาง เช่น ทริปแม่ฮ่องสอน, ทริปพะเยา

**keyword ที่ใช้ search ในกลุ่ม:**
```
"เปิดรับ"
"รับสมัคร"
"ใครสนใจไป"
"โอนมัดจำ"
"รอบนี้รับ"
"ปิดรับ"
"สรุปรายชื่อ"
```

**สัญญาณที่บอกว่าคนนี้ใช่:**
- โพสต์มีรายละเอียดทริป + ราคา + วิธีจอง
- มี comment ถามว่า "ยังว่างไหม" "จ่ายยังไง"
- เคยโพสต์แบบนี้มากกว่า 1 ครั้ง (= จัดสม่ำเสมอ)
- บอกให้ inbox หรือ LINE มาจอง (= ยังไม่มีระบบ)

---

### แหล่งที่ 2: Instagram / TikTok

**hashtag ที่ต้อง monitor:**
```
#ทริปเดินป่า #ทริปกลุ่ม #ไกด์ทริป #เที่ยวด้วยกัน
#ทัวร์ดำน้ำ #ทัวร์เดินป่า #tripthailand #hikeThailand
#ทริปภูเขา #ทริปทะเล #ชมรมเดินป่า
```

**สัญญาณที่บอกว่าคนนี้ใช่:**
- post รูปกลุ่มคนหลายคน พร้อม caption "ทริปที่ผ่านมา" หรือ "รอบถัดไป..."
- มี highlight story ชื่อ "ทริป" หรือ "จอง" หรือ "รับสมัคร"
- bio เขียนว่า "จัดทริป", "ไกด์", "trip organizer"
- มีคน comment ถามว่า "รอบหน้ามีไหม" แต่ไม่มีลิงก์จองในโพสต์

---

### แหล่งที่ 3: Network ส่วนตัว (ทำก่อนเลย)

ก่อนออกไปหาคนแปลกหน้า ให้ทำ 3 ข้อนี้ก่อนในสัปดาห์แรก:

1. **list ชื่อ 20 คนแรก** ที่รู้จักและอาจจัดทริปกลุ่ม — ไม่ต้องแน่ใจ แค่ "นึกถึง" ก็พอ
2. **ถามแต่ละคนตรงๆ** — "เคยจัดทริปกลุ่มบ้างไหม หรือรู้จักใครที่จัดบ้างไหม"
3. **ขอให้แนะนำต่อ 1 คน** — referral จากคนรู้จักปิดได้ง่ายกว่า cold outreach 3–4 เท่า

---

## ขั้นตอนที่ 2 — คัดกรองด่วน (30 วินาทีต่อคน)

**คนที่ควรทัก (ผ่านทั้ง 3 ข้อ):**
- [ ] จัดทริปกลุ่มจริง (มีหลักฐานในโพสต์/content)
- [ ] รับเงินหรือมีกระบวนการจองอยู่แล้ว (บอกให้โอน, inbox จอง)
- [ ] ดูเหมือนจะจัดต่อในอนาคต (ไม่ใช่จัดครั้งเดียว)

**คนที่ข้ามไปก่อน:**
- จัดทริปส่วนตัวกับเพื่อน ไม่รับเงิน
- บริษัททัวร์ขนาดใหญ่ที่มีระบบอยู่แล้ว
- คนที่โพสต์รูปเที่ยวแต่ไม่เคยชวนคนอื่นไปด้วย

---

## ขั้นตอนที่ 3 — สคริปต์ทักครั้งแรก

### หลักการสำคัญ
- **นำด้วยปัญหาของเขา** ไม่ใช่ชื่อแพลตฟอร์ม
- **เล่า 3 ขั้นตาม workflow จริง**: สร้างหน้าทริป → ส่งลิงก์ → รับเงิน/ตรวจสลิป
- **จบด้วยเรื่องสลิปปลอม** — เป็น pain ที่โดนใจที่สุด ทิ้งท้ายให้จำ
- **ไม่นำด้วยคำว่า "ฟรี"** — ใส่ได้แต่ต้องอยู่ท้าย เป็นตัวลด friction ไม่ใช่ตัว lead

---

### Facebook Inbox (แบบที่ 1 — เห็นโพสต์จัดทริป)

```
สวัสดีครับ เห็นโพสต์ทริป[ชื่อสถานที่]ในกลุ่ม[ชื่อกลุ่ม] ดูน่าไปมากเลยครับ

สังเกตว่าให้คนมา inbox จองทีละคนอยู่ เลยอยากแนะนำสิ่งที่น่าจะช่วยได้ครับ

มีระบบที่ทำให้สร้างหน้าทริปได้เลย ใส่รายละเอียดครบ ราคา กำหนดการ สิ่งที่รวมในราคา แล้ว copy ลิงก์ไปแปะในกลุ่มได้ทันที ลูกค้ากดจองเองได้เลยโดยไม่ต้องสมัครสมาชิก จ่ายเงินผ่านระบบ อัปโหลดสลิป แล้วระบบตรวจให้เองว่าสลิปจริงหรือปลอม ไม่ต้องเช็คมือเองทีละใบครับ

ถ้าสนใจลองคุยกัน 15 นาทีได้เลยครับ หรือดูก่อนได้ที่ sayhitrip.com ครับ
```

---

### Facebook Inbox (แบบที่ 2 — เห็นว่าจัดทริปบ่อย)

```
สวัสดีครับ เห็นว่าจัดทริปกลุ่มบ่อยมากเลยครับ

อยากแนะนำระบบที่น่าจะช่วยได้ครับ สั้นๆ คือ

① สร้างหน้าทริปใส่รายละเอียดครบ — ลูกค้าเปิดลิงก์แล้วเห็นทุกอย่างเลย ไม่ต้องถามซ้ำในแชต
② ส่งลิงก์เดียวในกลุ่มได้เลย — ลูกค้าจองเองได้โดยไม่ต้องสมัครสมาชิก
③ รับเงินในระบบ ระบบตรวจสลิปให้อัตโนมัติ — ไม่ต้องกลัวสลิปปลอมอีกแล้วครับ

ตอนนี้ใช้ได้ฟรี ลองดูได้เลยไหมครับ sayhitrip.com
```

### Instagram / TikTok DM

```

เห็นว่ามีคน comment ถามว่า "รอบหน้ามีไหม" เยอะมาก อยากแนะนำระบบที่ทำให้สร้างหน้าทริปส่วนตัวได้ แล้วส่งลิงก์ให้ follower จองเองได้เลย จ่ายเงินในระบบ มีตรวจสลิปปลอมให้อัตโนมัติด้วยครับ ไม่ต้องรับ DM ทีละคนแล้ว

ลองดูได้เลยนะครับ → sayhitrip.com
```

```

เห็นว่าให้คนมาติดต่อจองทาง LINE อยู่ อยากแนะนำสิ่งที่น่าจะช่วยได้ครับ

Say Hi Trip เป็นระบบที่ให้สร้างหน้าทริปใส่รายละเอียดได้ครบ แล้วส่งลิงก์เดียวให้คนจองได้เลย ลูกค้าจ่ายเงินผ่านระบบ อัปโหลดสลิป แล้วระบบตรวจสลิปให้เองว่าจริงหรือปลอม ไม่ต้องนั่งเช็คเองทีละใบครับ

สนใจลองคุยกันสั้นๆ ได้เลยครับ หรือดูก่อนได้ที่ sayhitrip.com ครับ
```

### โทรศัพท์ (ถ้ามีเบอร์จากโพสต์หรือรู้จักกัน)

**เปิดประโยคแรก (ต้องพูดใน 10 วินาที — เริ่มด้วยปัญหาของเขา):**
```
"สวัสดีครับ โทรมารบกวนแป๊บนึงนะครับ
เห็นว่าจัดทริปกลุ่มอยู่ มีระบบที่ช่วยเรื่องสร้างหน้าทริป
รับจอง และตรวจสลิปปลอมอัตโนมัติอยู่ครับ
อยากให้ลองดูไหมครับ ใช้เวลาคุย 10 นาทีพอ"
```

**ถ้าเขาถามว่า "มีอะไรพิเศษ" หรือ "ต่างจากอะไร":**
```
"หลักๆ สามอย่างครับ

หนึ่ง — สร้างหน้าทริปใส่รายละเอียดครบได้เลย ลูกค้าเปิดลิงก์แล้วเห็นทุกอย่าง ราคา กำหนดการ ของที่ต้องเตรียม ไม่ต้องถามซ้ำในแชต

สอง — copy ลิงก์ไปแปะในกลุ่ม LINE หรือ Facebook ได้เลย ลูกค้าจองเองได้โดยไม่ต้องสมัครสมาชิก

สาม — ลูกค้าโอนเงินแล้วอัปโหลดสลิป ระบบตรวจให้เองเลยว่าสลิปจริงหรือปลอม ไม่ต้องนั่งเช็คมือเองทีละใบแล้วครับ"
```

**ถ้าเขาถามว่า "คิดเงินเท่าไหร่":**
```
"ตอนนี้ใช้ได้ฟรีครับ ลองใช้ดูก่อนได้เลย"
```

**ถ้าเขาบอกว่า "ไม่มีเวลาตอนนี้":**
```
"ไม่เป็นไรเลยครับ ขอ LINE ไว้แค่ส่งลิงก์ให้ดูก่อนได้ไหมครับ
ถ้าสนใจค่อยนัดคุยใหม่ก็ได้"
```

**ถ้าเขาบอกว่า "ไม่สนใจ" หรือ "มีระบบแล้ว":**
```
"โอเคครับ ขอบคุณที่รับสายนะครับ
ถ้าวันไหนอยากลองดูก็แวะมาได้เลยครับ sayhitrip.com"
```

## ขั้นตอนที่ 4 — Follow-up Sequence

| วัน | action |
|-----|--------|
| วันที่ทัก | ส่งข้อความแรก |
| วัน 3 | ถ้าไม่ตอบ: ส่ง follow-up สั้นๆ (ด้านล่าง) |
| วัน 7 | ถ้าไม่ตอบอีก: ส่งครั้งสุดท้าย แล้วหยุด |

**Follow-up วัน 3 (ถ้าไม่ตอบ):**
```
"สวัสดีครับ ติดตามมาแป๊บนึงนะครับ 
ถ้ายังไม่ว่างก็ไม่เป็นไรครับ แค่ฝาก sayhitrip.com ไว้ก่อน 
ถ้าวันไหนอยากลองดูบอกได้เลยครับ"
```

**Follow-up วัน 7 (ครั้งสุดท้าย):**
```
"ครั้งสุดท้ายนะครับ ไม่รบกวนแล้ว 😄 
แค่อยากให้รู้ว่า Say Hi Trip พร้อมใช้งานแล้ว ถ้าวันไหนอยากลองดูยินดีครับ"
```

## ขั้นตอนที่ 5 — Demo / Setup Call 1:1

เมื่อเขาตอบรับ นัด call 20 นาที ทำ 3 อย่างนี้:

**10 นาทีแรก — ฟัง:**
- "ตอนนี้จัดการจองยังไงอยู่ครับ"
- "ส่วนที่เหนื่อยที่สุดคืออะไร"
- "มีทริปที่กำลังจะจัดอยู่ไหมตอนนี้"

**10 นาทีหลัง — ช่วย setup:**
- สร้าง account ให้เลย ในระหว่าง call
- กรอกข้อมูลทริปแรกด้วยกัน
- push ลิงก์ให้เขาเอาไปส่งในกลุ่มได้เลย

> เป้าคือเขา **ส่งลิงก์แรกได้ก่อนวางสาย** — ถ้าทำได้ retention สูงมาก
